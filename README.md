# Repeatly Landing Page

Landing page + privacy policy for [Repeatly](https://chromewebstore.google.com/detail/repeatly-loop-chain-youtu/mkpbpfhechamkebkgpdcfnkhfghdhgea), a free Chrome extension for looping YouTube video segments.

**Live site:** https://haritiwari442.github.io/landingPageRepeat/

## Files

- `index.html` — Landing page (home)
- `privacy.html` — Privacy policy (required by Chrome Web Store)

## Deploying to GitHub Pages

1. Push these files to the root of your `landingPageRepeat` repository
2. Go to repo Settings → Pages
3. Under "Source", select **main** branch and **/** (root) folder
4. Save — your site will be live at `https://haritiwari442.github.io/landingPageRepeat/` within ~1 minute
